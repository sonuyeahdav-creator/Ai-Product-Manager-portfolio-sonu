# Sonu Yadav AI PM Portfolio (v2)

Professional, dynamic single-page portfolio for Sonu Yadav, AI Product Manager & Product Marketing Manager.

## Features
- Modern, professional UI/UX (light/dark theme toggle, persisted)
- Dynamic: typewriter hero, animated stat counters, scroll-reveal sections, animated skill bars
- Filterable project cards (All / AI & Automation / Growth & Marketing)
- Humanized content in Sonu's own voice: short sentences, no em-dashes, no AI-sounding hype, only real verified metrics
- Fully responsive, single self-contained HTML file, no build step
- Accessible (prefers-reduced-motion supported), SEO meta tags

## Files
- `index.html` — the entire site (HTML + CSS + JS, single file)
- `README.md` — this file
