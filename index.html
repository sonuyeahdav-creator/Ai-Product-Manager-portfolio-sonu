Key Design Decision: Split-Context Multi-Agent Pattern

Early iterations combined parsing and scoring in a single LLM context window, causing hallucinations and JSON failures. Decoupling into two isolated agents achieved 100% downstream parsing reliability with custom JS repair routines.
